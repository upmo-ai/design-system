# Changelog

The four packages under `packages/` release together under one version, tagged `v<version>` in this repository. Each package also has its own `CHANGELOG.md`, written by Changesets.

## v0.3.4 (2026-11-01)

Sharp corner radii across tokens (--radius-xs: 2px, --radius-sm: 4px), smooth motion transitions for tabs, accordions, and form controls, centered topbar search launcher, and max-width layout containment.

## v0.3.3 (2026-11-01)

Compact density and UI typography adjustments: streamlined button dimensions, tightened alert containers, centered sidebar version number, and compact form control defaults.

## v0.3.2 (2026-10-31)

Compact navigation, menus, and icon-first controls across design system surfaces. Form alert box alignment corrected.

## v0.3.1 (2026-10-31)

`@upmo-ai/tokens` and `@upmo-ai/ui` tighten app page titles, sidebar items, and content insets. `@upmo-ai/icons` and `@upmo-ai/brands` have no code changes in this release. The docs site puts accessibility and responsive behaviour ahead of density.

## v0.3.0 (2026-10-21)

`@upmo-ai/tokens` adds `caret-idle`, the colour of the undrawn caret stroke (Queued, and the right stroke of Preparing and Planning), in the light, dark and high-contrast themes. The other packages have no changes in this release. Installing from GitHub needs pnpm 11.19 or later, as described on the [Install](https://design.upmo.dev/getting-started/install/) page.

## v0.2.0 (2026-10-17)

`@upmo-ai/ui` is tested with React 19.3 and Mantine 9.7. The peer ranges stay at React ^19.2.0 and Mantine ^9.4.0, so apps on v0.1.0 can move to v0.2.0 without other changes. The other packages have no changes in this release.

## v0.1.0 (2026-07-24)

First release of `@upmo-ai/tokens`, `@upmo-ai/icons`, `@upmo-ai/brands` and `@upmo-ai/ui`. Install them from the `v0.1.0` tag, as described on the [Install](https://design.upmo.dev/getting-started/install/) page.
