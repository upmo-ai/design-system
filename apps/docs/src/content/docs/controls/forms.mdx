The form controls follow the Upmo forms spec: the label always sits above the
control, required is the default (append "(optional)" for optional fields), the
description sits under the control, and the error message carries the danger
tone with an icon, wired to the control for assistive tech.

:::tip[Live previews are in Storybook]
Every component renders live, in light, dark and high contrast, in the
[Storybook gallery](https://design.upmo.dev/storybook/). Run it locally with
`pnpm --filter @upmo-ai/storybook dev`.
:::

## Field

`Field` is the field anatomy for native or custom controls: label, description
and error, associated via `htmlFor`, `aria-describedby` and `aria-invalid`. Pass
the control as a render function so the wiring lands on it.

```tsx
<Field label="Reach" description="What agents can access." error={err}>
  {(props) => <input type="text" {...props} />}
</Field>
```

Mantine inputs (`Input`, `Textarea`, `Select`) already implement the full
anatomy through their own `label`, `description` and `error` props, so prefer
those directly rather than wrapping them in a `Field`.

## Inputs

- **Input**: single-line text. `Input type="password"` for secrets.
- **Textarea**: long text; autosizes to 8 rows, then scrolls.
- **Select**: one of several; `data` is `{ value, label }[]`, searchable above
  about ten options.

## DateInput

A date field: type a date or pick one from the calendar. It wraps Mantine's
`DateInput` with the same anatomy as the other inputs (label above, description
under it, error below) and adds `optional`, which appends "(optional)" to the
label. The error line is Field's: the danger icon, then the message, announced
as an alert.

Dates follow Mantine 9: `onChange` receives a `YYYY-MM-DD` string, or `null`
when the field is cleared (`YYYY-MM-DD HH:mm:ss` with `withTime`). `value` and
`defaultValue` take that string, a `Date` or `null`, so hold the value as
`string | null`. Bound the choice with `minDate` and `maxDate` (a string or a
`Date`). The field shows the value as "15 Jan 2027" by default (`valueFormat`).

```tsx
import { DateInput } from '@upmo-ai/components/dates';

const [expiry, setExpiry] = useState<string | null>(null);

<DateInput
  label="Expiry"
  description="Tokens stop working at the end of this day."
  minDate={today}
  maxDate={inOneYear}
  value={expiry}
  onChange={setExpiry}
/>;
```

It comes from `@upmo-ai/components/dates`, not the main entry, and needs the
optional `@mantine/dates` and `dayjs` peers plus `@mantine/dates/styles.css`
(see [Install](/getting-started/install/)).

## Choices

- **Radio** (in `Radio.Group`): one of up to about five options.
- **Checkbox**: on/off that takes effect on submit, or several of a few.
- **Switch**: on/off that takes effect at once.
