`Button`, `IconButton`, `Badge` and `Spinner` from `@upmo-ai/components`, themed
by `@upmo-ai/theme`: sharp 2px action radius, emerald primary, familiar
icon-and-text.

:::tip[Live previews are in Storybook]
Every component renders live, in light, dark and high contrast, in the
[Storybook gallery](https://design.upmo.dev/storybook/). Run it locally with
`pnpm --filter @upmo-ai/storybook dev`.
:::

## Button

Mirrors Mantine's API: `variant` (filled, light, outline, default, subtle),
`size` (xs, sm, md, lg), `color` (for example `red` for destructive actions),
and the polymorphic `component` prop. Variant colours come from the theme.

- **Filled** (default): the one primary action per region. Emerald fill.
- **Light**: a secondary action on an emerald-soft ground.
- **Default**: a bordered, neutral action.
- **Subtle**: the quietest action, no border or fill at rest.
- Destructive actions use `color="red"`, always with a word, never colour alone.

## IconButton

An icon-only button. It requires an `aria-label`, which by default also becomes
its tooltip, so every icon control is both accessible and self-describing.

```tsx
<IconButton aria-label="Copy">
  <IconCopy size={18} />
</IconButton>
```

## Badge

Sentence-case text, tabular numerals, light variant by default. Use `color` for
the tone and `leftSection` for an optional icon.

## Spinner

A conventional loading spinner, themed to the emerald primary. Deliberately not
the caret: the caret is reserved for agent-liveness surfaces, so a generic
waiting state uses a familiar spinner.
