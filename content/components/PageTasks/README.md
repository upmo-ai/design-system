# PageTasks

A showcase of the Tasks list, built from the minimalist App Shell, clean Sidebar, Table, Alert, and sharp action buttons.

## What it demonstrates

- App shell: a 220px `Sidebar` on `surface-000` and a 48px global top bar. The top bar holds the brand logo, collapse navigation toggle, central search bar (`⌘K`), notifications bell with unread badge, quick add, and user profile avatar.
- The approval `Alert` sits above the list, with an inline sharp action button (`Review approval`).
- The dense data table features a search/filter toolbar, status filter button, group headers (`Active`, `Completed`), checkbox selection, cost tracking (`€ EUR`), artifact thumbnails with verification badge, and total spend summary.

## Responsive

Below `bp-md` the sidebar becomes the 56px rail. Below `bp-sm` it hides behind the top bar toggle. The table scrolls horizontally.
